Kernel-weighted quantile forecaster for GTA VI's launch-day Twitch viewers: it re-derives the launch-day curve shape from the past big launches in the case file and predicts hours 2-24 as five log-scale quantiles. Leave-one-out pinball loss 0.40 vs the house baseline's 0.93.

## Run it

```sh
python3 main.py
```
